          Quadric surfaces

          Every Exam 1 has a quadric question. Learn the sorting rule, then the nine cards.

          Sort any equation in four questions

          1. Is a variable missing? It is a cylinder along that variable’s axis: both squares the same sign → elliptic; opposite signs → hyperbolic; one squared and one not → parabolic.
          2. Is a variable to the first power (not squared)? It is a paraboloid that opens along that variable: the two squares have the same sign → elliptic (a bowl); opposite signs → hyperbolic (a saddle).
          3. All three squared: complete any squares, move the constant to the right and make it positive (multiply by −1 if needed). If the constant is 0 → cone.
          4. Count the minus signs on the left: none → ellipsoid; one → hyperboloid of one sheet (axis = the minus variable); two → hyperboloid of two sheets (axis = the plus variable).

          Trap to avoid: counting signs before the constant is +1. \(x^2+y^2-z^2=-1\) has one minus sign but is two sheets: multiply by −1 to get \(-x^2-y^2+z^2=1\).
